# Charity Manager

**Charity Manager** is a **client-server** application designed to revolutionize the way charitable organizations manage donations, volunteer coordination, and fundraising events. It operates as a **highly scalable telethon system**, allowing seamless tracking and administration of donations, ensuring transparency and accessibility for non-profits, donors, and volunteers alike.

Built on **a modular architecture**, the system ensures **scalability, maintainability, and performance optimization**, enabling real-time donation processing, event registrations, and powerful analytical insights to enhance strategic decision-making for charitable organizations.

## 🚀 Features
- **Comprehensive User Management** - Role-based access control for donors, volunteers, and administrators.
- **Real-Time Donation Tracking** - Secure and scalable handling of monetary and in-kind contributions.
- **Event Planning & Execution** - Create, schedule, and oversee charity events with ease.
- **Automated Reporting & Analytics** - Gain actionable insights on donation trends and engagement.
- **Live Notifications & Updates** - Ensure users stay informed about ongoing events and contribution statuses.

## 🏗️ Architecture and Project Structure
Charity Manager follows a **modular** architecture for enhanced **scalability, maintainability**, and **performance optimization**.

- **Backend:** Developed in **Java** using **Spring Boot**, it provides a highly responsive **REST API** for data processing and business logic execution.
- **Frontend:** A hybrid system using **JavaFX** (desktop) and **React** (web) for an intuitive and interactive user experience.
- **Database: SQLite**, with the flexibility to integrate alternative **relational databases** (except SQL Server and Postgres).
- **Security & Authentication:** JWT-based authentication for user validation and data protection.
- **Build & Dependency Management: Gradle**, streamlining development and deployment.
- **Testing Framework: JUnit 5**, ensuring code reliability through automated unit and integration testing.
- **Version Control & Collaboration: GitHub**, allowing for streamlined contributions and version tracking.
